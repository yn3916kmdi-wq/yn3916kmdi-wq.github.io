e-MyCloset利用規約English

プライバシーポリシー

制定日：2026年10月30日

Nomasa Yusuke（以下「運営者」）は、スマートフォン向けアプリ「e-MyCloset」（以下「本アプリ」）における利用者の情報の取り扱いについて、次のとおり定めます。

1. 基本的な考え方

本アプリは、利用者が登録した服の写真やコーデ、着用の記録などを、利用者の端末の中だけに保存します。運営者はサーバーを持っておらず、これらの情報を受け取ることはありません。

2. 端末の中に保存する情報

  • 登録した服の画像（切り抜いた画像）・名前・カテゴリ・色・季節・購入日・サイズ・価格・メモ・タグなどの情報
  • コーデ、着用の記録、カレンダーやコーデに添えた写真、旅行の荷造りリスト
  • アプリの設定（言語、テーマ、週の始まり、通貨、朝のお知らせの時刻など）

これらは本アプリを削除するか、「その他 → すべてのデータを消去」を行うと端末から削除されます。運営者が復元することはできません。

3. カメラ・写真へのアクセス

服を撮影したり、写真を選んだりするために、カメラと写真を利用します。撮影・選択した写真の切り抜きは端末の中で行い、写真を外部に送信することはありません。写真アプリへの保存は、利用者が選んだときだけ行います。

4. 通知

「朝のお知らせ」は、端末の中で予約する通知です。通知のために情報を外部へ送信することはありません。

5. 外部のサービスとの通信

(1) 服の切り抜きに使うプログラムの読み込み

切り抜きの精度を高めるため、Google が提供する MediaPipe のプログラムと学習済みモデルを、jsDelivr（CDN）と Google のサーバーから読み込むことがあります。このとき写真は送信しませんが、通信の際に端末の IP アドレスなどの一般的な通信の情報が各サービスに送られます。

(2) 広告（Google AdMob）

無料プランでは、Google LLC が提供する広告配信サービス「Google AdMob」を利用して広告を表示します。Google AdMob は、広告の配信・効果測定・不正の防止のために、次の情報を収集することがあります。

  • 広告 ID などの端末の識別子
  • IP アドレス（おおよその位置を推定するために使われることがあります）
  • 広告の表示・タップなどのアプリの利用状況
  • アプリや SDK の動作・不具合に関する診断情報

欧州経済領域など同意が必要な地域では、広告を表示する前に同意を確認します。同意の内容は「その他 → 広告のプライバシー設定」から変更できます。広告 ID は端末の設定からリセット・削除できます。Google による情報の取り扱いは Google のポリシー をご確認ください。プレミアムプランでは広告を表示せず、広告の仕組みも読み込みません。

(3) プレミアムプランの購入（App Store・Google Play・RevenueCat）

プレミアムプランの購入とお支払いは、Apple または Google のストアで行われ、運営者はクレジットカード情報などのお支払いの情報を受け取りません。購入の確認と管理のために、RevenueCat, Inc. が提供するサービス「RevenueCat」を利用しており、購入の履歴と、本アプリが自動で作る匿名の利用者 ID が RevenueCat に送られます。詳しくは RevenueCat のプライバシーポリシー をご確認ください。

6. バックアップ

「バックアップを作成」で作るファイルは、利用者が選んだ保存先（iCloud Drive、Google ドライブ、メールなど）に保存されます。運営者がこのファイルを受け取ることはありません。

7. 第三者への提供

運営者は、5. に記載したサービスによる収集を除き、利用者の情報を第三者に提供しません。法令に基づき開示を求められた場合は、この限りではありません。

8. お子さまの利用

本アプリは13歳未満のお子さまを対象としていません。

9. 情報の削除のご依頼

端末の中の情報は、本アプリの「すべてのデータを消去」または本アプリの削除で消すことができます。RevenueCat が保有する購入の履歴の削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

10. 欧州経済領域（EEA）・英国・スイスにお住まいの方へ

EU の一般データ保護規則（GDPR）などの法令に基づき、次のとおりお知らせします。

  • 取り扱いの責任者：本アプリにおける情報の取り扱いの責任者は運営者です（連絡先は 12. のとおり）。広告のための情報の取り扱いについては、Google のポリシーもご確認ください。
  • 取り扱いの根拠：広告のための情報の処理は、法令で同意が必要な場合は利用者の同意に基づき、それ以外の場合は広告の配信と不正の防止という正当な利益に基づいて行います。同意は、いつでも「その他 → 広告のプライバシー設定」から変更・撤回できます。購入の確認と管理（RevenueCat）は、プレミアムプランを提供するという利用者との契約の履行のために行います。
  • 利用者の権利：ご自身の情報について、アクセス・訂正・削除・処理の制限・異議・データポータビリティを求める権利、同意を撤回する権利、お住まいの国の監督機関に苦情を申し立てる権利があります。運営者は利用者の情報を保有していないため、端末の中の情報は、本アプリの中でご自身で確認・削除できます。そのほかのご依頼は、12. の連絡先までご連絡ください。
  • 国外への移転：Google と RevenueCat は、米国など EEA の外で情報を処理することがあります。移転は、各社のプライバシーポリシーに定める保護措置に基づいて行われます。
  • 保存期間：端末の中の情報は、利用者が削除するまで保存されます。Google と RevenueCat が集めた情報の保存期間は、各社のポリシーに従います。
